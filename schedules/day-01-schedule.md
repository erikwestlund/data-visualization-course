# Day 1 Schedule: Workflow And First Visualization

Class block: 1:30-5:00 pm (3.5 hours).

## Main Goal

Students leave with the course project working, `source("updater.R")` tested, and one first visualization module opened or started.

## Schedule

| Time | Segment | Materials | Notes |
|---:|---|---|---|
| 1:30-1:40 | Welcome and course framing | `slides/day-01-intro-and-workflow.qmd` | Keep this brief. |
| 1:40-1:55 | Introductions | Slides or verbal prompt | Pair intros are faster than full-room intros. |
| 1:55-2:20 | Course philosophy and workflow preview | Day 1 slides | Do not over-teach grammar yet. |
| 2:20-3:05 | Course materials walkthrough | `modules/01-workflow-and-basics/01_course-materials.qmd` | Main event. Go slowly. Everyone clicks along. |
| 3:05-3:15 | Break and tech catch-up | RStudio/Positron help | Use this as setup buffer. |
| 3:15-3:55 | First visualization demo | `modules/01-workflow-and-basics/02_first-visualization.qmd`; references: `modules/01-workflow-and-basics/03_ggplot2-dictionary-and-cheatsheet.qmd`, `modules/01-workflow-and-basics/04_dplyr-tidyr-dictionary-and-cheatsheet.qmd` | Emphasize `p1`, `p2`, `p3` object workflow and point students to the cheatsheets. |
| 3:55-4:25 | Student practice | `practice/templates/01-workflow-and-basics/01_explore-and-visualize.qmd` copied to `practice/work/` | Goal is one `glimpse()`, one count, one plot attempt. |
| 4:25-4:30 | Wrap and next steps | Verbal | Remind: work in `practice/work/`. |
| 4:30-5:00 | Open practice and support | Practice work, setup help | Use the extra time for troubleshooting and getting everyone to a successful render. |

## If Time Runs Short

Cut slide depth, not workflow. The minimum successful Day 1 is project open, updater tested, and first plot started.

## Instructor Priorities

- Confirm project root and paths.
- Confirm `source("updater.R")` works.
- Confirm `practice/work/` exists.
- Confirm students understand `modules/` versus `practice/work/`.
- Confirm students know where to find the `ggplot2` and `dplyr`/`tidyr` dictionary modules.
